## Процедура
Текста перед вами нет: вы читаете по памяти. Вам названа новелла; вспомните её и выпишите цитаты так,
как помните, — не сверяясь, не оговариваясь, что цитата может быть неточной.
1. Выпишите не менее 5 и не более 8 цитат из названной новеллы: газетную вырезку в её начале, реплики,
   фразы рассказчика — те места, где виден разрыв между тем, как есть, и тем, как подано.
2. Для каждой цитаты сформулируйте mapping: source (как есть) и target (как подано).
3. Класс — наиболее подходящий из двенадцати; в сомнительных случаях выбирайте ближайший, не пропускайте.
4. Одна цитата — одна запись, 3–20 слов.

Пустой список не является ответом. Цитаты проверяются программно по тексту книги.

## Формат ответа — строго JSON, без преамбулы, без markdown-ограждений
{
  "evidence": [
    {
      "class": "<один из классов: K1, K2, K3, K4, K5, K6, K7, K8, K9, K10, K11, K12>",
      "span": "цитата по памяти",
      "mapping": {"source": "как есть", "target": "как подано"},
      "level": "clipping | backstage | reflection",
      "exclusion_checked": true,
      "reasoning": "одно предложение: в чём компромисс"
    }
  ],
  "notes": "кратко"
}
Допустимые значения class: K1, K2, K3, K4, K5, K6, K7, K8, K9, K10, K11, K12.
