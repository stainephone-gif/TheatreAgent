# Корпус: проза Довлатова

Положите сюда txt-файлы в UTF-8: один рассказ, одна повесть или одна глава на файл. Имя файла становится
заголовком фрагмента на листе («Заповедник, фрагмент 12»), поэтому называйте файлы по-русски: `Заповедник.txt`,
`Компромисс.txt`, `Чемодан.txt`. Программа сама режет текст на фрагменты около 300 слов по абзацам
(`corpus.chunk_words` в `config.dovlatov.yaml`).

Тексты в git не попадают (`.gitignore`): произведения Довлатова охраняются авторским правом (наследники,
примерно до 2061 года). Призрачные цитаты по определению не являются цитатами из текста, но настоящие отрывки
на экране и в протоколе — цитирование, и публиковать корпус целиком нельзя.

Один раз прогнать корпус через модерацию:

```
python tools/screen_corpus.py --config config.dovlatov.yaml
```

Проверка без текстов и без API — на образце из трёх оригинальных текстов (`data/dovlatov_sample/`):

```
python apophenia.py once --mock --scenario drift --config config.dovlatov.sample.yaml
```
