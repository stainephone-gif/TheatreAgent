# Корпус: «Компромисс»

Сюда кладутся новеллы книги, подготовленные утилитой (один раз):

```
python tools/prepare_kompromiss.py путь/к/Компромисс.txt
```

Получится `00 Вступление.txt` и `01 Компромисс первый.txt` … `12 Компромисс двенадцатый.txt` (UTF-8). Титул,
копирайт, послесловие и примечания отбрасываются. Файлы в git не попадают: текст охраняется авторским правом.
